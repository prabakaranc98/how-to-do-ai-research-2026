# LLMs and Cognitive Systems

This domain is for language-model work that draws from cognition, predictive processing, memory, reasoning, representation learning, self-correction, and agent behavior.

Keep major initiatives in named folders. Domain-specific datasets, environments, cognition notes, agent traces, and representation analyses should stay inside the initiative folder when they are created.

This domain should stay connected to the shared [`Integrated AI Research Stack`](../research-craft/integrated-ai-research-stack.md): representation learning defines the internal state, mechanistic interpretability audits it, post-training/RL changes policies in the sibling [`post-training-and-rl/`](../post-training-and-rl/) domain, and cognitive control closes the loop through agent behavior.

## Initiatives

### Relationship To Post-Training and RL

Post-training and RL now live as a top-level domain: [`../post-training-and-rl/`](../post-training-and-rl/).

This folder should still connect to that work through cognition, representation learning, uncertainty, self-correction, memory, and agent behavior.

### Representation Learning for LLM Cognition

Study how language models organize concepts, memory, uncertainty, goals, plans, values, and feedback signals in hidden state space.

The core question:

**Which representations make reasoning, post-training, reward learning, and agent control possible?**

### Cognitive Control in Language Agents

Study how language agents monitor progress, detect failure, use memory, update plans, and correct themselves through prediction error or uncertainty.

Related exploratory work currently lives in [`../mech-interpt/sprints/003-predictive-coding-small-language-model-agents/`](../mech-interpt/sprints/003-predictive-coding-small-language-model-agents/).
